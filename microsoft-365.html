FAQ

Questions fréquentes

Quelle est la différence entre Microsoft 365 et Office ?+
Microsoft 365 est un abonnement qui inclut les applications Office, le stockage cloud (OneDrive), la messagerie (Exchange) et Teams, avec des mises à jour continues. Office est une licence achetée une seule fois, qui ne comprend que les applications de bureau, sans services cloud associés.
Puis-je obtenir un devis pour plusieurs utilisateurs ?+
Oui. Indiquez-nous le nombre d'utilisateurs et vos besoins via le formulaire de contact : nous vous proposons une offre groupée avec tarif dégressif selon le volume.
Les licences sont-elles vendues directement sur ce site ?+
Non, ce site est une vitrine présentant nos offres Microsoft. Chaque commande fait l'objet d'un devis personnalisé établi avec notre équipe, afin de garantir la meilleure formule pour votre situation.
Combien de temps faut-il pour activer une licence ?+
Une fois le devis validé, l'activation d'une licence Microsoft 365 ou Office prend généralement entre quelques heures et 48h ouvrées, selon le volume de licences et la configuration nécessaire.
Proposez-vous un accompagnement à la migration ?+
Oui, nous accompagnons la migration de votre messagerie et de vos données vers Microsoft 365, ainsi que le paramétrage de vos postes Windows, sans interruption de votre activité.
