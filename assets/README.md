# Microsoft brand assets

Drop your official files from **Microsoft Partner Center → Partner Marketing Center**
(or your CSP distributor's brand portal) into this folder using the exact
filenames below. Both `index.html` and `microsoft-365.html` already reference
these paths with a safe fallback (a generic icon/text is shown until the real
file exists), so the site upgrades automatically the moment a file lands here
— no code changes needed.

| File to add | Used for |
|---|---|
| `assets/microsoft-logo.svg` | The Microsoft logo (four squares + wordmark), shown in the hero badge and the Microsoft partner card |
| `assets/csp-badge.svg` | Your "Cloud Solution Provider" partner badge/seal |
| `assets/icons/word.svg` | Word app icon |
| `assets/icons/excel.svg` | Excel app icon |
| `assets/icons/powerpoint.svg` | PowerPoint app icon |
| `assets/icons/outlook.svg` | Outlook app icon |
| `assets/icons/teams.svg` | Microsoft Teams app icon |
| `assets/icons/onedrive.svg` | OneDrive app icon |

## Notes

- SVG preferred (crisp at any size); PNG with a transparent background also
  works — just keep the same filename minus the extension mismatch (if you
  only have `.png` files, tell me and I'll adjust the `<img>` `src` paths).
- Use the files **unmodified** — no recoloring, stretching, or adding effects
  — per Microsoft's Partner brand guidelines. Keep the minimum clear space
  Microsoft's guidelines specify around the logo and badge.
- The CSP badge/program name and exact usage terms depend on your current
  Partner Center enrollment — if you're not sure which badge asset you're
  entitled to display, check the "Co-marketing" or "Brand" section of your
  Partner Center dashboard before publishing.
